# VirusTotal

Samples of Monitor Mu files reported to antivirus vendors as false positives, so their analysts can download them directly.

Monitor Mu is a free Windows tool by Wellington N. Verzola that supervises MU Online game clients. It never reads or writes game memory, never injects code and never modifies the game.
